📚 ИНТЕГРАЦИЯ СПРАВКИ С ПРИЛОЖЕНИЕМ

Теперь во многих местах приложения есть кнопка «?», которая открывает
соответствующий раздел справки прямо в приложении.

🎯 ГДЕ ДОБАВЛЕНЫ КНОПКИ «?»:

• Редактор свойств виджета — для каждого виджета своя страница:
  Button, TextView, EditText, ImageView, LinearLayout, RelativeLayout,
  ScrollView (H/V), WebView, ProgressBar, ListView, Spinner, CheckBox,
  Switch, SeekBar, CalendarView, AdView, MapView.

• Дизайнер, События, Компонент — в шапке проекта.
• Редактор логики — учитывает текущее событие (onCreate).
• Инструменты — отдельная кнопка «?».
• Настройки приложения — пункт «Справка» в конце списка.

📖 ЯКОРЯ СПРАВКИ

• 217 якорей для всех разделов онлайн-справки.
• Универсальная система: якорь → страница справки.
• Добавлены новые разделы (будут пополняться).

🛠 ТЕХНИЧЕСКИЕ ИЗМЕНЕНИЯ

• Класс WidgetHelpMapper — сопоставление типов виджетов с якорями.
• Полный переход на новую систему якорей (block-*).
