🚀 Начало работы

Sketchware Pro — это среда разработки Android-приложений прямо на смартфоне. Создавайте приложения с помощью визуального конструктора.

  1. Создайте проект: на главном экране нажмите кнопку «+».
  2. Настройте проект: укажите имя, package name, версии.
  3. Откройте дизайнер: перетащите виджеты (TextView, Button, WebView).
  4. Добавьте логику: откройте редактор логики, перетащите блоки.
  5. Соберите APK: нажмите кнопку «Запустить».

🧩 Блоки и логика

В редакторе логики блоки делятся на категории:

  • Переменные — хранение значений.
  • Списки — массивы данных.
  • Управление — условия (if), циклы (forever, repeat).
  • Операторы — математика, строки, сравнения.
  • Файлы — работа с файлами и SharedPreferences.
  • View — работа с элементами экрана.
  • Компоненты — Dialog, Timer, Firebase и др.

🔍 Проверка логики блоков

Функция находит ошибки в блоках до сборки APK.

6 правил проверки

  • 🔴 Пустое условие в if / ifElse / while
  • 🔴 Несуществующий компонент (dialog2, webView1, ...)
  • 🟡 Пустой обязательный параметр (doToast без текста)
  • 🟡 Тривиальное условие (if true / if false)
  • 🟡 Недостижимые блоки — висят отдельно
  • 🟡 Бесконечный цикл forever без break

3 режима проверки

  • ✓ Проверить текущее событие — кнопка рядом с поиском блоков.
  • 📋 Проверить весь экран — кнопка рядом с ✓.
  • 🔨 Перед сборкой APK — автоматически, все экраны проекта.

💾 Резервные копии

Sketchware умеет создавать резервные копии проектов.

  • Вручную: долгий тап на проекте → «Создать резервную копию».
  • Автоматически: после успешной сборки APK — в Настройках → «Автобэкап после сборки».

Файлы сохраняются в /sdcard/.sketchware/backups/.

📦 Экспорт .skproj

Переносимая папка проекта — для обмена между устройствами.

Экспорт

Долгий тап на проекте → «Экспорт переносимой папки (.skproj)».

Поделиться

Долгий тап на проекте → «Поделиться проектом» — откроется системное меню отправки.

Что внутри

  • manifest.json — метаданные формата
  • project.json — данные проекта
  • screens/ — экраны
  • logic/ — блоки событий
  • components/ — компоненты
  • variables/, lists/ — переменные и списки
  • resources/ — картинки, звуки, шрифты
  • config/, build_settings.json, libraries.json

❓ Частые вопросы

Где сохраняются проекты?

/sdcard/.sketchware/data/<scId>/

Как импортировать .skproj?

В разработке. Скоро появится в разделе «Инструменты».

Почему APK не устанавливается?

Разрешите установку из неизвестных источников: Настройки → Безопасность.

Как сообщить об ошибке?

Пришлите лог из Настройки → Журнал отладки в тему на 4PDA.
