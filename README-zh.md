# Sketchware Pro 多语言本地化 (RasNikGal)

🌍 **5 种语言 + 系统:** 🇷🇺 俄语 · 🇬🇧 英语 · 🇨🇳 中文 · 🇮🇳 印地语 · 🇺🇦 乌克兰语

📖 **其他语言的文档:** [🇷🇺 RU](README.md) · [🇬🇧 EN](README-en.md) · [🇨🇳 中文](README-zh.md) · [🇮🇳 हिन्दी](README-hi.md) · [🇺🇦 UK](README-uk.md)

这是一个 **Sketchware Pro** 项目的一个**分支**，添加了**完整的五语种本地化**。

### 支持的语种

- 🇷🇺 俄语
- 🇬🇧 英语
- 🇨🇳 中文
- 🇮🇳 印地语
- 🇺🇦 乌克兰语
- 🌐 系统语言

### 切换语言

侧边菜单 → **界面语言** → 选择语言。

### 智能回退

如果系统语言不受支持（如德语、阿拉伯语），应用会自动使用**英语**。

### 安装

从 [Releases](https://github.com/rasnikgal-pixel/Sketchware-Pro/releases/latest) 页面下载 `app-release.apk`。
