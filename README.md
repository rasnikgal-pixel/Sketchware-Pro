## 📌 О проекте

**Sketchware Pro** — это мощный инструмент для создания Android-приложений прямо на смартфоне с помощью визуального конструктора (блоков). Он позволяет собирать полноценные приложения без необходимости писать код вручную, хотя при желании можно использовать Java и Kotlin.

**Цель этого форка** — сделать среду разработки **доступной для русскоязычных пользователей**, особенно для новичков, которые только начинают изучать Android-разработку и не владеют английским языком в достаточной степени.

### Что переведено?

Перевод охватывает **все уровни интерфейса**:
*   **Основные экраны:** Дизайнер, редактор логики, редактор кода.
*   **Менеджеры:** Управление блоками, компонентами, событиями, библиотеками и ресурсами.
*   **Все диалоги:** Создание, редактирование, настройки.
*   **Системные сообщения:** Ошибки компиляции, уведомления (Toast, Snackbar), предупреждения.
*   **Категории блоков:** Переменные, Списки, Управление, Операторы, Математика, Файлы, View, Компоненты.

## 🛠️ Сборка из исходного кода

Если вы хотите собрать приложение самостоятельно, вам потребуется **Gradle** и **Android SDK**.

### Требования
*   **Java Development Kit (JDK) 17** или выше.
*   **Android SDK** с установленной платформой `android-36` (или той, что требуется в `build.gradle`).
*   **Gradle** (рекомендуется использовать wrapper `./gradlew`).

### Шаги сборки

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/rasnikgal-pixel/Sketchware-Pro.git
    cd Sketchware-Pro
    ```

2.  **Настройте `local.properties`** (если собираете не в Android Studio):
    Создайте файл `local.properties` в корне проекта и укажите путь к Android SDK:
    ```properties
    sdk.dir=/путь/до/вашего/Android/SDK
    ```

3.  **Соберите APK:**
    ```bash
    ./gradlew assembleMinApi26Debug
    ```
    Готовый APK будет лежать в `app/build/outputs/apk/minApi26/debug/`.

> **Примечание:** Для сборки требуются `google-services.json` и `SKETCHUB_API_KEY`. В официальном репозитории они не предоставлены. Для тестовой сборки можно создать фиктивный `google-services.json` (как описано в инструкциях сообщества).

## 📄 Лицензия и дисклеймер

Это **неофициальная модификация** Sketchware Pro. Проект не связан с оригинальными разработчиками.

*   **Лицензия:** Проект распространяется под той же лицензией, что и оригинальный Sketchware Pro.
*   **Ответственность:** Приложение предоставляется «как есть». Автор не несёт ответственности за любой ущерб, возникший в результате использования данного программного обеспечения.
*   **Публикация:** Публикация этого модифицированного приложения в Google Play или других магазинах **запрещена** в соответствии с условиями оригинального проекта.
