# Багатомовна локалізація Sketchware Pro (RasNikGal)

🌍 **5 мов + системна:** 🇷🇺 Російська · 🇬🇧 English · 🇨🇳 中文 · 🇮🇳 हिन्दी · 🇺🇦 Українська

📖 **Документація іншими мовами:** [🇷🇺 RU](README.md) · [🇬🇧 EN](README-en.md) · [🇨🇳 中文](README-zh.md) · [🇮🇳 हिन्दी](README-hi.md) · [🇺🇦 UK](README-uk.md)

Цей репозиторій — **форк** проєкту **Sketchware Pro**, у який додано **повну п'ятимовну локалізацію** інтерфейсу.

### Підтримувані мови

- 🇷🇺 Російська
- 🇬🇧 English
- 🇨🇳 中文
- 🇮🇳 हिन्दी
- 🇺🇦 Українська
- 🌐 Системна

### Перемикання мови

Бокове меню → **Мова інтерфейсу** → виберіть мову.

### Розумний відкат

Якщо системна мова не підтримується (наприклад, німецька чи арабська), застосунок автоматично переходить на **англійську**.

### Встановлення

Завантажте `app-release.apk` зі сторінки [Releases](https://github.com/rasnikgal-pixel/Sketchware-Pro/releases/latest).

### Повна документація

## 🆕 Що нового в 7.8.5

- **GPU-прискорення** редактора блоків (перемикач у налаштуваннях)
- **Швидка панель властивостей** — клік по віджету: зверху ID, Текст, Підказка, Розмір, Відступи
- **Подвійний клік** — діалог (Події / Усі властивості / Редактор блоків)
- **Перевірка перед збіркою** — AppCompat/Material3 + кнопка «Виправити та зібрати»
- **Нова палітра** «Керування застосунком» — закрити / згорнути / розгорнути
- **Локалізація** — усі налаштування 5 мовами, 0 хардкоду

⚠️ **Перезберіть ваші застосунки!**
