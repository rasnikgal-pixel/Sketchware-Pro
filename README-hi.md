यह रिपॉज़िटरी **Sketchware Pro** परियोजना का एक **फोर्क** है, जिसमें इंटरफ़ेस का **पूर्ण पाँच-भाषीय स्थानीयकरण** जोड़ा गया है।

### भाषा बदलें

साइड मेनू → **इंटरफ़ेस भाषा** → भाषा चुनें।

### स्मार्ट फ़ॉलबैक

यदि सिस्टम भाषा समर्थित नहीं है (जैसे जर्मन या अरबी), ऐप स्वचालित रूप से **अंग्रेज़ी** पर स्विच कर देगा।

### इंस्टॉलेशन

[Releases](https://github.com/rasnikgal-pixel/Sketchware-Pro/releases/latest) पृष्ठ से `app-release.apk` डाउनलोड करें।

### पूरा दस्तावेज़

## 🆕 7.8.5 में नया

- **GPU त्वरण** ब्लॉक संपादक के लिए (सेटिंग्स टॉगल)
- **त्वरित गुण पैनल** — विजेट पर टैप करें, ऊपर ID, टेक्स्ट, संकेत, आकार, स्पेसिंग
- **डबल-टैप** — डायलॉग (इवेंट्स / सभी गुण / ब्लॉक संपादक)
- **निर्माण से पहले जाँच** — AppCompat/Material3 + "ठीक करें और बनाएँ" बटन
- **नया पैलेट** "ऐप नियंत्रण" — बंद / छोटा करें / पुनर्स्थापित करें
- **स्थानीयकरण** — सभी सेटिंग्स 5 भाषाओं में, 0 हार्डकोड
